# Wall Envy Quick Style Guide

## Core Variables
Defined in `assets/css/variables.css`.

- `--bg-midnight: #061525`
- `--bg-deep: #0B1D2D`
- `--card: #13283A`
- `--gold-primary: #D89A2B`
- `--gold-light: #E8B94F`
- `--gold-deep: #A96F19`
- `--purple: #4B1D68`
- `--purple-highlight: #702B87`
- `--text-primary: #F5F3EE`
- `--text-secondary: #AAB4B9`
- `--divider: #304354`
- Transition gradient only: `--brand-gradient: linear-gradient(135deg,#061525 0%,#0B1D2D 55%,#4B1D68 100%)`

## Buttons
- Primary CTA (`.btn-primary`): `linear-gradient(90deg,#A96F19 0%,#D89A2B 50%,#E8B94F 100%)`, text `#F5F3EE`.
- Secondary (`.btn-outline`): transparent background, `1px` border `#D89A2B`, text `#F5F3EE`.

## 80/15/5 Rule
- 80% navy surfaces: `--bg-midnight`, `--bg-deep`, `--card`.
- 15% neutral readability: `--text-primary`, `--text-secondary`, divider lines.
- 5% accents: gold and purple reserved for CTAs, wordmark highlights, and section-transition gradients.
