Wall Envy SEO Master Implementation Plan

Implementation handoff for David — wallenvy.com.au

Purpose

This document consolidates the three Wall Envy SEO plans into one practical implementation roadmap. It is designed to be the single source of truth for technical SEO, on-page SEO, local SEO, image SEO, content expansion, internal linking, authority building and ongoing measurement.

Primary business objective: generate qualified enquiries for direct-to-wall printing across the Central Coast, Newcastle, Lake Macquarie and the Hunter Region.

Primary SEO theme: Direct to Wall Printing Central Coast & Newcastle.

Core principle: Google should be able to understand three things immediately — what Wall Envy does, where Wall Envy operates, and which customer types Wall Envy serves.


Platform note — important

The current Wall Envy site is being managed in Squarespace. Where the source documents included hand-written robots.txt, sitemap.xml or HTML file examples, treat those as implementation concepts rather than instructions to create duplicate files manually inside Squarespace.

For the current Squarespace site:
• Use Squarespace’s automatically generated sitemap and submit /sitemap.xml in Google Search Console.
• Do not create a second manual sitemap unless the platform changes.
• Do not attempt to replace Squarespace’s robots.txt unless there is a specific indexing issue and Squarespace supports the required control.
• Apply title tags, meta descriptions, headings, image alt text, redirects and page content through Squarespace page settings and content blocks.
• Add custom schema only where it improves or supplements Squarespace’s existing structured data and has been validated.

If Wall Envy later moves to a fully custom-coded website, the HTML/schema examples from the technical handoff can then be adapted to that environment.

David’s migration process:
1. Export/list every current live URL.
2. Mark KEEP or CHANGE.

4. Implement 301 redirects in Squarespace URL Mappings.
5. Update all internal links to point directly to the final URL.
6. Update navigation.
7. Test old URLs return a single 301 to the correct live page.
8. Re-submit important new URLs through Search Console.
9. Watch Search Console for 404s and redirect errors.

9. Image SEO and performance

This is a high-priority area because Wall Envy is image-heavy.

Before upload:
• Resize images to the display dimensions reasonably required.
• Compress without visible quality loss.
• Prefer modern efficient formats when Squarespace supports them automatically.
• Do not upload huge original camera files when a much smaller web version is sufficient.

Filename standard:
service-subject-location.jpg

Examples:
cafe-direct-wall-printing-central-coast.jpg
commercial-office-wall-mural-newcastle.jpg
school-wall-printing-central-coast.jpg

Alt text standard:
Describe what is actually visible first. Add service/location only when it is genuinely useful context.

Good:
Direct-to-wall printed coffee mural behind tables in a Central Coast cafe

Good:
Company logo printed directly onto a reception wall in a Newcastle office

Bad:
Wall Envy best wall printing Central Coast Newcastle Hunter mural printer

Do not add alt text to purely decorative images if the platform allows them to be ignored appropriately.

Image audit checklist:
1. Hero images compressed.
2. Project images compressed.
3. Descriptive filenames used for new uploads.
4. Meaningful images have unique, accurate alt text.
5. No keyword stuffing.
6. Mobile pages checked for slow-loading oversized images.

16. Technical SEO QA

For every release or major SEO change, check:

Indexability
• Important page returns HTTP 200.
• No accidental noindex.
• Canonical points to the intended URL.
• Sitemap contains the intended canonical URL.
• Old changed URLs 301 to the correct destination.
• No redirect chains.

Page structure
• Exactly one primary H1.
• H2/H3 hierarchy is logical.
• Title is unique.
• Meta description is unique.
• Main content is visible as text, not only embedded in images.
• Navigation links are crawlable.

Mobile/performance
• Hero image is not unnecessarily large.
• No major layout shift from images.
• Page remains usable on mobile.
• Images use sensible dimensions/compression.

Content quality
• Service and location are clear.
• Copy is not duplicated from another service/location page.
• Claims are accurate.
• CTA works.
• Internal links point to final URLs.

After publishing
• Inspect changed page in Search Console.
• Request indexing if the change is substantial.
• Record change date for later performance comparison.


17. Authority and backlinks

Prioritise genuine local and industry relevance.

Best opportunities:
• Completed commercial customers linking to the Wall Envy project/case study.
• Local chambers/business organisations.
• Suppliers or industry partners.
• Genuine Australian/local directories that are maintained and reputable.
• Relevant local media or business publications.
• Architecture, design, hospitality, education or commercial fitout partners where a real relationship exists.

Avoid:
• Purchased bulk backlink packages.
• Hundreds of unrelated overseas directories.
• Exact-match keyword spam links.
• Guest-post networks with no audience or relevance.

Local citations/directories mentioned in the source handoff included True Local, Yellow Pages, hipages and Houzz. David/business owner should assess relevance and category fit before creating listings rather than treating every directory as mandatory.


18. Monthly SEO operating routine

Once implementation is complete, SEO becomes an ongoing operating process.

Monthly:
1. Search Console → Performance → Queries.
2. Identify relevant queries with impressions and average positions around 8–20.
3. Find the page receiving those impressions.
4. Improve that page for the query if it matches genuine search intent.
5. Review pages losing clicks/impressions.
6. Check indexing errors.
7. Add new completed projects.
8. Add new genuine reviews to Google Business Profile.
9. Update project photos.
10. Build one or two strong local links rather than chasing volume.

Quarterly:
• Review titles/meta descriptions for CTR opportunities.
• Review location coverage.
• Review internal linking.
• Audit old/large images.
• Check broken links and redirects.
• Review which service pages generate enquiries.
• Decide next content based on actual Search Console data, not keyword guesses alone.

20. Definition of done

The initial SEO implementation is complete when:

1. Google Search Console is verified and sitemap accepted.
2. All core pages are indexable and use the intended canonical URLs.
3. Misspelled Sports & Sponsorships references are fixed and redirected where needed.
4. Every important page has a unique title, meta description and one primary H1.
5. Every service page has a distinct keyword/search intent.
6. Main service pages contain enough useful content for a customer to understand the offer.
7. Important images are compressed and meaningful images have accurate alt text.
8. Internal links connect services, process, surfaces, projects, FAQs and contact.
9. Google Business Profile is accurate and points to the live website.
10. Any custom schema is valid, accurate and non-duplicative.
11. Major URL changes have 301 redirects.
12. Search Console shows the updated pages can be crawled and indexed.
13. There is a repeatable monthly SEO review process.
